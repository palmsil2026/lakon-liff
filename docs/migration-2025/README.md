## ขั้นตอน (5 ขั้น)

| # | ใคร | ทำอะไร |
|---|---|---|
| 1 | คุณปาล์ม (~5 นาที) | เข้าเมลเก่า → Drive → โฟลเดอร์ `appsheet/data` → **Share ทั้งโฟลเดอร์** ให้ `palm.work2026@gmail.com` (Viewer พอ) |
| 2 | คุณปาล์ม | เลือก **วันตัดยอด** แล้วหยุดกรอกข้อมูลในแอปเก่า (สำคัญกับ **Office** ที่ Deployed อยู่) |
| 3 | สคริปต์ | รัน `migrate-data.gs` (ไฟล์ในโฟลเดอร์นี้) ในเมลใหม่ → ก๊อปทุกสเปรดชีต+ไฟล์แนบเข้าโฟลเดอร์ `Migration-2025` + สร้างชีต `Migration_Report` |
| 4 | ทีม AI | รัน `verifyReport()` เทียบแท็บ×แถวทุกไฟล์ → จับคู่ข้อมูลเข้าชีตระบบใหม่ (งานโค้ดฝั่งโรงน้ำทำต่อใน repo `origin-hq`) |
| 5 | คุณปาล์ม | ยืนยันข้อมูลครบ → เลิกใช้/ลบแอป AppSheet เก่า — ต้นฉบับในเมลเก่ายังอยู่เป็น backup |

## กติกาความปลอดภัย

- สคริปต์ **อ่านอย่างเดียว** กับของเก่า: ทำสำเนา (เจ้าของ = เมลใหม่) ไม่แก้/ลบ/ย้ายต้นฉบับ
- โฟลเดอร์ใหญ่ไม่ติดลิมิต 6 นาที: สคริปต์พักเองแล้วตั้ง trigger รันต่ออัตโนมัติ
- ตรวจรับด้วย `Migration_Report` — คอลัมน์ "ตรวจ" ต้องเป็น `OK` ทุกแถวก่อนปิดของเก่า
- ห้ามเอาโค้ดโรงน้ำมาไว้ใน repo นี้ (กติกา `plant-systems/README.md`) — ขั้น 4 ที่แตะโค้ดระบบ ทำใน `origin-hq`
