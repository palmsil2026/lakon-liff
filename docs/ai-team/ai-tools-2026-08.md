## 1) clasp + GitHub Actions — เลิกแปะโค้ดเอง ⭐ คุ้มสุด

**ปัญหาเดิม:** ทุกครั้งที่ทีม AI แก้ `secretary/Code.gs` คุณปาล์มต้องเปิด Apps Script → ก็อปทับ → Manage deployments → New version เอง และ `STATUS.md` ต้องคอยจดว่า "อะไรรอวาง"

**ของที่มี:**
- [`google/clasp`](https://github.com/google/clasp) — CLI ทางการของ Google (ตอนนี้ v3.x) `clasp push` = อัปโค้ดขึ้น Apps Script, `clasp create-version` / `clasp create-deployment -i <deploymentId>` = ออกเวอร์ชันใหม่ **บน deployment เดิม** (ตรงกับกติกาเราเป๊ะ: ห้าม New deployment เพราะ URL เปลี่ยนแล้ว webhook LINE พัง)
- [`ericanastas/deploy-google-app-script-action`](https://github.com/ericanastas/deploy-google-app-script-action) + [คู่มือ CI/CD ของ 8apps](https://www.8apps.co/blog/shipping-google-workspace-addon-clasp-github-actions) — ตัวอย่าง workflow พร้อมใช้
- ถ้าอยากให้ AI สั่ง deploy เองในแชท: มี [MCP ครอบ clasp](https://github.com/redmorestudio/clasp-enhanced-mcp) อีกชั้น

**ภาพหลังทำเสร็จ:** merge เข้า `main` → GitHub Actions push โค้ดขึ้น GAS + ออกเวอร์ชันใหม่ให้เอง → พิมพ์ "เช็คระบบ" ในไลน์เห็น `CODE_VERSION` ตรงกับ repo ทันที · ตาราง "รอ deploy GAS เลขา" ใน `STATUS.md` หายไปเลย

**ข้อควรระวัง:** ต้องเก็บ credential (`CLASPRC_JSON` หรือ service account) เป็น GitHub Secret — repo นี้เคยเป็น public ควรเช็คว่าเป็น private แล้ว และเริ่มจากโหมดกดสั่งเอง (`workflow_dispatch`) ก่อน ค่อยเปลี่ยนเป็นอัตโนมัติเมื่อมั่นใจ

## 2) งานพรีเซนต์ลูกค้าองค์กร (OEM / ส่งน้ำองค์กร)

**ข่าวดีคือของที่ต้องใช้ เรามีอยู่แล้วเกือบครบ:**

| ตัวช่วย | ใช้ทำอะไร | สถานะของเรา |
|---|---|---|
| skill `pptx` | ให้ Claude สร้างไฟล์ `.pptx` จริง แก้ต่อใน PowerPoint/Slides ได้ | ✅ มีแล้ว |
| skill `theme-factory` / `canvas-design` | คุมสี-ฟอนต์ให้ทุกสไลด์เป็นชุดเดียวกัน / ทำโปสเตอร์-ใบปลิว | ✅ มีแล้ว |
| `/design` (ของใหม่ 17 ส.ค. 2026) | ร่างหน้าตางานออกแบบเป็น artboard แก้ด้วยการคลิกได้ | ✅ มีแล้ว (research preview) |
| **Canva connector** | ดึง/สร้าง/ export งานใน Canva ได้จากแชท — ใช้ brand kit ละกอนได้ | ⚠️ **ติดตั้งแล้วแต่ยังปิดอยู่ในแชทนี้** → เปิดในตั้งค่า connector ของแชท |
| Gamma connector | พิมพ์ประโยคเดียวได้เด็คสวยทั้งชุด เหมาะกับเด็คที่เน้นเร็ว | ยังไม่ได้ติดตั้ง (มีในไดเรกทอรี claude.ai) |
| Brightdeck connector | สร้างเด็คที่ export เป็น .pptx/PDF ได้ | ยังไม่ได้ติดตั้ง |

**วิธีที่แนะนำจริง ๆ (จากรีวิวเทียบเครื่องมือปี 2026):** อย่าให้ AI ทำทั้งเด็คทีเดียวจบ — ผลลัพธ์จะสวยแต่เนื้อกลวง ให้แบ่งเป็น
1. **เนื้อหา/โครงเรื่อง** = ให้ทีม AI ร่าง โดยดึงของจริงจาก `docs/ai-team/brand-lakon.md` + `company-origin-labs.md` + ตัวเลขกำลังผลิตจาก `plant`
2. **ความสวย** = Canva (ใช้ brand kit เดิม ป้าย/ฉลากจะได้ไปทางเดียวกัน) หรือ Gamma ถ้าอยากได้เร็ว
3. **ไฟล์ส่งลูกค้า** = `.pptx` หรือ PDF เสมอ (ลูกค้าองค์กรชอบแก้/ส่งต่อในไฟล์ตัวเอง)

> 💡 ควรทำ "เด็คแม่แบบ" ของออริจิ้น แล็บส์ 1 ชุด (โรงงาน · มาตรฐาน อย./GMP · 6-Step Purification · กำลังผลิต · เคสงาน OEM · ราคา) แล้วทุกครั้งที่มีลูกค้าใหม่ก็แค่สลับหน้าราคา/โจทย์ — สั่งทีม AI ทำได้เลย ไม่ต้องรอเครื่องมือใหม่

## 3) Google Sheets MCP — ให้ AI แตะชีตได้ตรง ๆ

ตอนนี้ Claude อ่านตัวเลขโรงน้ำ/ร้านผ่าน GAS อย่างเดียว งานล้างข้อมูลเลยต้องรอคน
มี MCP server ฟรีหลายตัว ([freema/mcp-gsheets](https://mcpservers.org/servers/freema/mcp-gsheets), Google Workspace MCP) ที่อ่าน-เขียน-แก้ชีตได้ครบ

**งานที่ได้ประโยชน์ทันที:** ของค้างใน `STATUS.md` — ชื่อ "Palm" ค้าง 26 แถวใน 7 แท็บ กับแถวขยะใน `HR_Staff` (งานนี้เป็นชีตฝั่งโรงน้ำ ต้องให้แชท `origin-hq` ทำ)
**ข้อควรระวัง:** ให้สิทธิ์เขียนกับชีตของจริง = พลาดแล้วเจ็บ → เริ่มจากสิทธิ์ **อ่านอย่างเดียว** ก่อน และห้ามแตะแท็บ `Payments` / `CashRemits` ตามกติกาเดิม

## 4) LINE Bot MCP (ทางการของ LINE)

[`line/line-bot-mcp-server`](https://github.com/line/line-bot-mcp-server) — ต่อ AI เข้ากับ LINE OA โดยตรง: ส่งข้อความ/Flex หาลูกค้ารายคน, broadcast หาผู้ติดตามทั้งหมด, ดูโปรไฟล์, เช็คโควตาข้อความ
เหมาะกับ: แจ้งโปรฯ น้ำละกอน, แจ้งรอบส่ง, ทวงบิลแบบสุภาพ
**ระวัง:** LINE บอกเองว่ายังเป็น preview + การ broadcast คือส่งหาลูกค้าจริง → ต้องให้คุณปาล์มเคาะข้อความก่อนส่งทุกครั้ง (กติกาข้อ 2 ใน CLAUDE.md)

จาก [What's new ของ Claude Code](https://code.claude.com/docs/en/whats-new):

- **คุยข้ามแชทได้ (สิงหา wk32) + พิมพ์ `@` เรียกอีกแชท (wk33)** → ตรงกับปัญหาเราที่สุด: `palm-hq` / `origin-hq` / `olddays-hq` แก้ไฟล์ชนกัน ต่อไปส่งงานข้ามแชทได้เลยไม่ต้องเล่าใหม่

- **`/design`** (17 ส.ค.) — ร่าง UI/งานออกแบบเป็น artboard
- **Artifacts เรียก connector ของคนเปิดหน้าได้ (wk29)** — อนาคตทำหน้ารายงานผู้บริหารที่ดึงข้อมูลสดได้โดยไม่ต้องพึ่ง GitHub Pages + GAS
- **Routines / cloud session** — ตั้งเวลาให้ agent ทำงานเองรายวัน (เช่น สรุปยอดเช้า 8 โมง)
