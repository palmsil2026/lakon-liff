# 🏭 P&K โรงขวด — ระบบใหม่ (แทน AppSheet 4 แอปในเมลเก่า)

> **คนละบริษัทกับโรงน้ำละกอน** — ห้ามชี้ระบบนี้ไปที่ชีต OriginSystem หรือ GAS ของโรงน้ำ
> โครงสร้างธุรกิจ: ลูกค้า (แบรนด์น้ำดื่ม/น้ำแข็ง ~578 ราย) สั่งขวด → ผลิต → (สกรีนสีถ้ามี) → ส่ง → เก็บเงิน (สด/เครดิต+ใบวางบิล)

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | คืออะไร | ใครใช้ |
|---|---|---|
| `gas/Code.gs` | GAS **"P&K System" v2** — API + ฐานข้อมูล (สเปรดชีต `PKSystem`) ทุกการเขียนล็อกกันชนกัน + ลง ActivityLog อัตโนมัติ | หลังบ้านทุกแอป |
| `index.html` | แอปทีมงาน v2: **ล็อกอินชื่อเล่น+PIN รายคน** · เมนูตามแผนก · ลงเวลาเข้า-ออก · รับออเดอร์ · งานผลิต/สกรีนรายสินค้า (ลงดี/เสีย → สต๊อกเดินเอง) · ส่งของเป็นงวด · สต๊อก · ออกบิล/ใบวางบิล | พนักงานทุกคน |
| `exec/index.html` | บอร์ดบริหาร v2: แจ้งเตือน (เลยกำหนดส่ง/ชำระ/เก็บ, สต๊อกต่ำ, ลืมลงเวลา) · ผลิต-ของเสีย 30 วัน · เงินสดรายคน · พนักงาน+จัดการ PIN · ฟีดทุกการกระทำ · **ประธานปรับราคา + ประวัติ** | คุณปาล์ม + ประธาน (`PK_EXEC_KEY`) |

URL จริงหลัง merge เข้า `main`: `https://palmsil2026.github.io/palm-hq/pk/` และ `…/pk/exec/?key=รหัส`

## ติดตั้งครั้งแรก (คุณปาล์มทำ ~10 นาที)

1. ล็อกอิน `palm.work2026@gmail.com` → [script.new](https://script.new) → ตั้งชื่อ **P&K System** → วาง `gas/Code.gs` ทั้งไฟล์
2. รัน `setupPkSystem()` (สร้างชีต `PKSystem` + ตั้ง `PK_SHEET_ID` เอง — รันซ้ำได้ ปลอดภัย)
3. Script properties เพิ่ม: `PK_EXEC_KEY` (รหัสผู้บริหาร — ตั้งยาว ๆ เดายาก) และ `PK_KEY` (รหัส API สำรองสำหรับสคริปต์/แชทการเงิน — พนักงานไม่ใช้)
4. รัน `importLegacyAccounting()` → ดึงบิล/ลูกหนี้/ลูกค้าเก่าจากสแนปช็อต "ระบบบัญชี"
5. Deploy → New deployment → **Web app** (Execute as: Me / Anyone) → คัดลอก URL
6. เอา URL วางแทน `PASTE_PK_GAS_WEBAPP_URL_HERE` ใน `pk/index.html` + `pk/exec/index.html` → commit push
7. เปิดบอร์ด `pk/exec/?key=รหัส` → **จัดการพนักงาน → เพิ่มพนักงาน** (ชื่อเล่น+PIN) → ให้ทีมล็อกอินแอป `pk/` ด้วยชื่อเล่น+PIN ของตัวเอง
   (แก้โค้ด GAS ครั้งถัดไป: Manage deployments → ✏️ → New version เท่านั้น + bump `CODE_VERSION`)

## วงจรข้อมูล v2 (ซิงก์กันหมดอัตโนมัติ)

- ลงออเดอร์ → เกิด **งานผลิตแยกรายสินค้า** (+งานสกรีนถ้ามี) อัตโนมัติ
- ทีมผลิต/สกรีน กด "ลงผลผลิต" (ดี/เสีย + สาเหตุ) → **ของดีบวกเข้าสต๊อกเอง** ของเสียฝั่งสกรีนหักสต๊อกเอง
- คนส่งของกด "ส่งรอบนี้" (ส่งบางส่วนได้) → **หักสต๊อกตามจำนวนส่งจริง** + สถานะออเดอร์เดินเอง
- ออกบิลจากออเดอร์ / บิลอิสระ (ขายหน้าโรง — หักสต๊อกที่บิล) → เครดิตเข้าใบวางบิล → เก็บเงิน
- **ทุกการกระทำลง ActivityLog ว่าใครทำอะไรเมื่อไหร่** (ตัวตนจาก PIN ที่ล็อกอิน ไม่ใช่พิมพ์เอาเอง)
- ยกเลิกออเดอร์ = งานผลิต/สกรีนที่เหลือถูกยกเลิกตาม · ยกเลิกบิลต้องใส่เหตุผล + คืนสต๊อกให้ (บิลอิสระ)

## กติกาข้อมูล (ให้ทุกแชทอ่าน — รวมแชท "แอพการเงินโรงขวด")

- สเปรดชีต **`PKSystem`** คือฐานเดียวของ P&K: `Customers` `Products` `Orders` `Production` `ScreenJobs` `Bills` `Statements` `PriceHistory` `Settings`
- **เงินรับจริง/ลูกหนี้ อ่านจากแท็บ `Bills`** (สถานะ: ชำระแล้ว / ค้างชำระ / วางบิลแล้ว · ประเภท: เงินสด / เครดิต) — ใบวางบิลอยู่ `Statements`
- แชทการเงินเพิ่มแท็บใหม่ได้ (เช่น `Expenses`) แต่**ห้ามเปลี่ยนชื่อคอลัมน์/ความหมายของ `Bills` และ `Statements`** — ถ้าจำเป็นให้จดใน STATUS.md แล้วบอกกันก่อน
- หาคอลัมน์จากหัวตารางเสมอ อย่าอ้างเลขคอลัมน์ตายตัว
- **ราคาสินค้า**: ประธานใหญ่ปรับผ่านบอร์ดบริหารเท่านั้น (`pkPriceSet` — ล็อกด้วย `PK_EXEC_KEY`) ทุกครั้งลง `PriceHistory` · หน้ารับออเดอร์เติมราคากลางให้อัตโนมัติแต่แก้มือได้ (ราคาจริงต่อรองหน้างานได้)
