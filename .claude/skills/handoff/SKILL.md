# ส่งงานกลับให้คุณปาล์มแบบตัดสินใจได้ใน 10 วินาที

ปัญหาจริงที่เกิดอยู่: มีหลายแชทค้างสถานะ "รอคุณปาล์มตอบ" พร้อมกัน แต่คำถามอยู่คนละแชท คุณปาล์มเลยไม่รู้ว่าค้างอะไรอยู่บ้าง

## ห้ามถามแบบนี้

> "อยากให้ทำแบบไหนดีครับ" · "มีอีกหลายทางเลือก ลองบอกมาได้เลย"

= โยนภาระคิดกลับไปให้เจ้าของ ผิดกติกาข้อ 3 ใน `CLAUDE.md`

## ให้ถามแบบนี้

```
❓ ต้องเคาะ: <หัวข้อสั้น ๆ>
เพราะ: <ทำไมผมเลือกเองไม่ได้ — 1 บรรทัด>

A) <ทางเลือก> → ได้ <ผล> · เสีย <ต้นทุน/ข้อเสีย>
B) <ทางเลือก> → ได้ <ผล> · เสีย <ต้นทุน/ข้อเสีย>

👉 ผมแนะนำ A เพราะ <เหตุผลสั้น ๆ>
ตอบแค่ "A" หรือ "B" พอครับ ที่เหลือผมทำต่อเอง
```

กติกา:
- ตัวเลือกไม่เกิน 3 ข้อ ต้องมีข้อแนะนำเสมอ
- ทุกข้อต้องบอก**ทั้งสิ่งที่ได้และสิ่งที่เสีย** ไม่ใช่ขายข้อเดียว
- เรื่องเงิน / ส่งข้อความออกไปหาคนอื่น / แก้ข้อมูลจริง = ต้องถามเสมอ ห้ามเดา
- เรื่องเล็ก ย้อนกลับได้ ความเสี่ยงต่ำ = **ทำไปเลย อย่าถาม**

## ก่อนจบทุกงานที่ยังมีของค้าง

อัปเดต `docs/ai-team/decisions-pending.md` (**เขียนทับ ห้าม append** — ที่นี่คือ "ค้างอะไรอยู่ตอนนี้" ไม่ใช่ประวัติ):

```markdown
# รอคุณปาล์มเคาะ (อัปเดต <วันที่> โดยแชท <ชื่อแชท>)

| # | เรื่อง | ตัวเลือก | แนะนำ | แชท/repo |
|---|---|---|---|---|
| 1 | ... | A/B | A | ... |
```

เจอข้อไหนที่ตอบไปแล้ว/ไม่เกี่ยวแล้ว → ลบแถวนั้นทิ้ง แล้ว commit + push ทันที
ถ้าไม่มีของค้าง ให้เขียนว่า "ตอนนี้ไม่มีอะไรรอเคาะ" — อย่าปล่อยไฟล์ค้างสถานะเก่า
