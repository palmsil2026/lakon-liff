# แตะชีตของจริง — กติกากันบั๊กเลื่อมคอลัมน์

บั๊กชนิดนี้เกิดมาแล้วอย่างน้อย 3 รอบใน repo นี้ (ชีต `HR_Staff` เลื่อม, ห้องผู้บริหารอ่านคอลัมน์ชีตโรงงานผิด, อ่านสมุดรับเงิน v14 ผิดสเปก) ทุกรอบมาจากสาเหตุเดียวกัน: **โค้ดจำตำแหน่งคอลัมน์ไว้ แต่คนเพิ่มคอลัมน์ในชีต**

## กฎเหล็ก 4 ข้อ

1. **หาคอลัมน์จากชื่อหัวตารางเสมอ** อ่านแถวหัวมาทำ map `{ชื่อหัว → index}` แล้วค่อยอ่านค่า
   ห้ามเขียน `row[4]` หรือ `getRange("G2:K")` ตรง ๆ เพราะทีมอื่นเพิ่มคอลัมน์ได้โดยไม่แจ้ง
2. **หัวตารางหาไม่เจอ = หยุดแล้วบอก** อย่าเดาคอลัมน์ใกล้เคียง อย่าเขียนทับ ให้ throw/log ว่าไม่เจอหัวชื่ออะไรในแท็บไหน
3. **เขียนกลับเฉพาะคอลัมน์ที่ตั้งใจแก้** ใช้ index ที่ได้จากหัวตาราง ไม่เขียนทั้งแถวรวด (ทับ PIN / Staff_ID / คอลัมน์ที่แอปอื่นใช้)
4. **แถวไม่มีคีย์ห้ามหายเงียบ** ถ้าแถวไหนอ่านไม่ได้/ไม่มีทะเบียน ให้รายงานจำนวนแถวที่ข้าม ไม่ใช่กรองทิ้งเฉย ๆ

## แท็บที่มีข้อตกลงพิเศษ

| แท็บ | สิทธิ์ | หมายเหตุ |
|---|---|---|
| `Payments`, `CashRemits` | **อ่านอย่างเดียว ห้ามเขียน** | เป็นของระบบขาย v14 · palm-hq อ่าน `Order_ID · ยอด · วิธี(เงินสด/โอน) · Remit_ID · วันที่` |
| `HR_Staff`, `HR_Payroll`, `HR_Attendance` | เขียนได้ (ผ่านโมดูล HR) | เงินเดือนเห็นได้เฉพาะสิทธิ์ CEO/กรรมการ |
| ชีตโรงน้ำ (`Orders_Sales`, `Orders_OEM`, แผนผลิต, รอบผลิต, `ProductionLog`, `Deliveries`, `Customers`) | เจ้าของคือ `origin-hq` | จะแก้ข้อมูลในนี้ ให้ส่งงานไปแชท `origin-hq` อย่าแก้ข้ามที่ |

ถ้าจะเปลี่ยน**ชื่อแท็บ** หรือ**ความหมายคอลัมน์**ที่ตารางข้างบนอ้างถึง ต้องแจ้งอีก repo ก่อนเสมอ แล้วจดใน `STATUS.md` ทั้งสองฝั่ง

## ชื่อคนในชีต

ทะเบียนใช้ **"ปาล์ม" / "คุณกอล์ฟ"** (ภาษาไทย) — ข้อมูลเก่าที่ยังเป็น `Palm` ทำให้รายงานรายเซลส์แยกเป็น 2 คน
เจอชื่อรูปแบบเก่าตอนอ่านชีต: **รายงานว่าเจอกี่แถว แท็บไหน** อย่าไล่แก้เองถ้าเป็นชีตของอีก repo

## ก่อนรันสคริปต์ที่เขียนลงชีตจริง

- รันโหมด dry-run ก่อน: พิมพ์ว่าจะแก้แถวไหน คอลัมน์ไหน จากค่าอะไรเป็นอะไร
- ให้คุณปาล์มดูผล dry-run แล้วค่อยรันจริง (กติกา "เรื่องเงิน/ข้อมูลจริง = ถามก่อนทำ")
