# ตรวจหน้าจอด้วยตา ก่อนขึ้นของจริง

แก้ CSS แล้วเดาว่าสวย = บั๊กแบบ "ปุ่มยืนยันอยู่ใต้ fold" หรือ "ตัวหนังสือไทยล้นการ์ด" หลุดขึ้นของจริงมาแล้ว
เครื่องมือมีอยู่แล้ว: Chromium + Playwright ติดตั้งพร้อมใช้ (`PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers` — **ห้ามรัน `playwright install`**)

## ขั้นตอน

1. เสิร์ฟไฟล์: `python3 -m http.server 8080` แล้วเปิด `http://localhost:8080/<path>`
2. แคป 3 ขนาดเป็นอย่างน้อย
   - **390 × 844** (iPhone — คนใช้จริงส่วนใหญ่ ทั้งเซลส์ คลัง และลูกค้าที่สั่งน้ำ)
   - **768 × 1024** (แท็บเล็ตหน้างาน)
   - **1280 × 800** (เดสก์ท็อป)
3. หน้าไหนมีโหมดมืด (`exec/`, `board/`) ให้แคปทั้งสองโหมด (`colorScheme: 'dark'`)
4. **ส่งรูปให้คุณปาล์มดูก่อน push** — ถ้าเป็นการแก้หน้าตา ให้แคปทั้งก่อนและหลัง

## เช็กลิสต์ที่ต้องดูในรูป

- [ ] ปุ่มหลัก (สั่งเลย / ยืนยัน / บันทึก) **เห็นได้โดยไม่ต้องเลื่อน** บนจอ 390px — ถ้าไม่เห็น ให้ทำเป็นแถบติดขอบล่าง
- [ ] ตัวหนังสือไทยไม่ล้น ไม่ถูกตัดกลางคำ (ชื่อลูกค้า/ชื่อสินค้ายาว ๆ ต้องมี `text-overflow` หรือขึ้นบรรทัดใหม่)
- [ ] ปุ่ม/ช่องกดได้ ไม่เล็กกว่า ~44px และไม่ติดกันจนกดพลาด
- [ ] ตัวเลขเงิน/จำนวน เรียงตรงหลัก (`font-variant-numeric: tabular-nums`)
- [ ] สีสถานะ (เขียว/แดง/ส้ม) ยังอ่านออกทั้งสองโหมด และไม่ใช่ตัวบอกสถานะอย่างเดียว — ต้องมีข้อความกำกับด้วย
- [ ] ไม่มีแถบเลื่อนแนวนอนโผล่ทั้งหน้า (ตารางกว้างให้เลื่อนเฉพาะในกล่องของมัน)
- [ ] ฟอนต์ที่ตั้งใจใช้ โหลดขึ้นจริง (ไทยไม่ตกไปเป็นฟอนต์ระบบ)

## เจอบั๊ก

แก้แล้วแคปใหม่ ทำซ้ำจนผ่านทุกข้อ ค่อย commit — อย่า push โดยบอกว่า "น่าจะโอเค"
