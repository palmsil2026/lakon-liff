# วางงาน GAS คุณเลขาให้จบ ไม่ตกหล่น

ไฟล์ `secretary/Code.gs` มีหลายแชทแก้ (เลขา / ทีม AI / ห้องผู้บริหาร-HR / ร้านกาแฟ)
บั๊กที่เกิดซ้ำจริงในประวัติ repo คือ **ลืม bump เวอร์ชัน · ลืมอัปเดต STATUS · วางทับจากไฟล์เก่า** — เช็กลิสต์นี้กันสามอย่างนั้น

## ก่อนแก้

1. `git pull` เสมอ — ห้ามแก้จากไฟล์ที่ค้างในเครื่อง งานของอีกแชทจะหายเงียบ ๆ
2. อ่าน `STATUS.md` — ดูว่ามีของค้างรอวางอยู่ก่อนหน้าหรือเปล่า ถ้ามี งานเราจะไปรวมเป็นชุดเดียวกับเขา

## หลังแก้ ก่อน commit

3. **bump `CODE_VERSION`** (บรรทัดเหนือ `healthCheck` ใน `secretary/Code.gs`)
   - รูปแบบ `YYYY-MM-DDx` — วันเดิมแก้ซ้ำให้เลื่อนตัวอักษร (`23a` → `23b` → `23c`)
   - ถ้าแก้ `Code.gs` แล้วไม่ได้ bump = ผิด ไม่ต้องหาเหตุผล ให้ bump
4. **อัปเดต `STATUS.md`** (เขียนทับ ห้าม append):
   - ตาราง "รอ deploy GAS เลขา" → เพิ่มบรรทัดงานเรา + ชื่อแชทที่ทำ
   - แถว GAS ในตารางเทียบ repo → เปลี่ยนเป็น "⏳ รอวาง (repo = <เวอร์ชันใหม่>)"
5. commit + push ทันที ห้ามดองข้ามวัน

## สรุปให้คุณปาล์มท้ายงาน (ต้องมีทุกครั้ง)

เขียนเป็นข้อความสั้น 4 บรรทัดนี้ อย่าเขียนยาวกว่านี้:

```
📋 ต้องวาง GAS: ใช่
ไฟล์: secretary/Code.gs (จาก main เท่านั้น)
เวอร์ชัน: 2026-08-23e
วิธี: เปิด Apps Script → ก็อปทับทั้งไฟล์ → Manage deployments → แก้ deployment เดิม → New version
      (ห้าม New deployment — URL เปลี่ยนแล้ว webhook LINE/ลิงก์บอร์ดพัง)
เช็กว่าขึ้นจริง: พิมพ์ "เช็คระบบ" ในไลน์ ต้องเห็นเวอร์ชันตรงกับข้างบน
```

ถ้างานนี้ไม่ได้แตะ `Code.gs` ให้บอกตรง ๆ ว่า **"ไม่ต้องวาง GAS — push แล้วขึ้น Pages เองใน ~1 นาที"**

## เมื่อถูกถามว่า "ของจริงตรงกับ repo รึยัง"

- เวอร์ชันใน repo: `grep CODE_VERSION secretary/Code.gs`
- เวอร์ชันที่รันจริง: ให้คุณปาล์มพิมพ์ "เช็คระบบ" ในไลน์ (หรือยิง endpoint `?action=healthCheck`)
- ตรงกัน = ไม่มีงานค้าง → อัปเดต `STATUS.md` ให้สะท้อนความจริงทันที
